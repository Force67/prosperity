// SHADOW OF THE COLOSSUS (CUSA08809, PS4)
// Boots, loads its modules, returns from LoadInitialWorld and runs the main loop
// with the renderer live, and it DOES render a real image -- see it with
// +DELTA_GPU_PRESENT_ADDR=0x804e660000. The scanout is black because the draw
// that carries that image forward writes through a UAV (its PS exports no
// colour and ends in image_store), which the PS4 renderer does not implement,
// so it is dropped for having no colour target. Separately, the world content
// streaming behind the main loop burns the engine's whole 1 GiB CPU heap and it
// then walks off its own "no free block" sentinel at eboot+0x1a371 (2026-08-01).

// Show the target the game actually renders into.
// +DELTA_GPU_PRESENT_ADDR=0x804e660000

// The scanout composite binds that target and reads black from it. PSWHITE
// paints the screen white (so geometry/target/blend/present are all fine) and
// PSTEX exports a sampled texel instead of the shader's maths -- bindings 0
// and 1 both come back black.
// +DELTA_GPU_PSWHITE=1
// +DELTA_GPU_PSTEX=2
// +DELTA_GPU_TEXMISS=1  (41 unresolved T# bindings a run)
// +DELTA_GPU_DRAWSEQ=260 +DELTA_GPU_DRAWRT=1 +DELTA_GPU_WHYDROP=1

// The world-load spin hammers sched_yield (6.4M calls in 20 s), which our
// default maps to a pause; a real host yield lets the load finish first.
// +DELTA_SCHED_YIELD_REAL=1

// Cap read throughput so the streaming loader cannot outrun its own finalizer.
// +DELTA_IO_MBPS=60

// Watch the CPU heap's free map drain (address from the crash's r9).
// +DELTA_GUEST_POPCNT=8000940af8:5e00:1000

// Skip CGame::LoadInitialWorld's gate: no crash, but nothing to draw either.
// +DELTA_SOTC_SKIP_WORLDWAIT=1

// Job-system research knobs from the pre-fix era, off by default. The loader
// thread and job system work now, so these are unlikely to be what you want.
// +DELTA_SOTC_7CORE=1
// +DELTA_SOTC_JOBFIX=1
// +DELTA_SOTC_JOBMOVE=1
// +DELTA_SOTC_FORCE_WORLDDONE=1
// +DELTA_SOTC_FORCE_PAYLOAD=1
// What the FIOS2 layer was asked for, when a load never completes.
// +DELTA_FIOS_TRACE=1
